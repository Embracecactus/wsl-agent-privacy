# 会话、权限与内容

## 会话记录与交叉使用

Claude 的项目列表只显示当前项目和分支可见的本地会话。清理历史、切换目录、首次登录、退出后未保存或筛选范围，都会导致“没有会话记录”。先检查当前目录和全局项目筛选，再决定是否恢复。

Claude 读取 Codex 工作目录、会话摘要或文件改动时，读取到的文本会作为工具结果发回 Claude。反方向同理。网络隔离保护 API 连接的出口，不能阻止已授权文件内容离开本机。共享工作树同时被两个 Agent 修改时，先检查进程、Git 状态、时间戳和未跟踪文件，不把未知变更归因给任一 Agent。

GitHub 登录、OAuth、MCP 和浏览器登录都可能向服务商提交账号、仓库、授权范围和请求内容。固定代理能约束该连接出口。它不能隐藏账号本身，也不能替代仓库权限和 OAuth 授权范围审查。

GitHub SSH 使用 SSH 密钥和主机验证，HTTPS 使用 token 或 OAuth。两者的网络出口都应从实际客户端进程验证。不要把 token、cookie、完整 remote URL、会话 ID 或 SSH 私钥写入聊天、命令输出、Skill 资料或诊断报告。

## 工具结果最小化

可从 Skill 目录在本机检查用户选定的一份 JSONL。扫描只输出工具事件的类别计数。

~~~bash
read -erp '本次授权检查的 session JSONL 路径: ' session_file
/usr/bin/python3 -I scripts/audit.py session "$session_file"
~~~

需要跨工具复核时，先在本地筛选用于业务的片段，再决定是否把原文交给另一端。Claude --continue 从当前项目继续最近会话，--resume 的项目列表可检查当前筛选；Codex 使用 codex resume。切换专用 HOME、项目或分支筛选时，先查对应的保存位置。在普通交互式 Bash 配置好入口后，新终端会加载相应启动文件；source ~/.bashrc 只用于让当前终端立即采用修改。

处理地址、时区、设备信息、媒体或日志时，先限定读取范围。优先要求工具输出成功/失败、摘要、计数或已审核字段。需要展示值时，先确认它确实用于业务诊断。

对合成敏感标记做过的工具结果脱敏实验，可以证明该标记在特定 CLI 路径没有进入后续请求。它不等于通用个人信息识别器，也不覆盖 MCP、子 Agent、后台工具、历史压缩或客户端自动上下文。任何日常脱敏 hook 应先以合成样本、失败关闭和恢复场景验证。

## 权限与设置告警

设置中的 Bash 允许规则若在命令其余部分前使用通配符，可能扩大可执行参数范围。把通配符移到子命令之后，或写出精确参数。改前先查看规则来源和调用处，改后用预期命令与相邻危险参数进行验证。

例如一个为 awk 片段建立的允许规则，通配符放在 awk 程序文本之前时可能让新增选项也自动获准。把规则收敛为精确程序文本，或把通配符限定在已确认的最后参数位置。先导出设置副本并在单条无害命令上回归，再恢复正常会话。

清理会话、浏览器 profile、Desktop 数据或虚拟机文件前，分别列出保留、移动和删除对象。恢复只针对本次留下的可识别备份。不要把清理造成的空会话列表解释为网络或账号问题。

启动时的审批属于 Agent 的工具权限机制，不能由网络隔离代替。只为稳定、已验证的低风险检查添加允许项。不要为了免审批扩大 shell、文件或网络权限。

历史工具输出未发现本地公网 IP，只能表明该检索范围内没有文本命中。没有历史抓包、服务端审计或完整会话覆盖时，不能据此声明没有泄露。
